Install

Up and running in minutes.

Aurvo isn't on Google Play yet, so you install the app file (APK) yourself. Choose the way that suits you.

Downloader Easiest

All on the TV, no phone needed.

  1. Install Downloader by AFTVnews from Google Play on your TV.
  2. When asked, allow unknown apps for Downloader. You can also turn this on under Settings → Apps → Security.
  3. Enter github.com/Jwsson/Aurvo-releases/releases/latest and open it.
  4. Pick the .apk file under "Assets", then install and open Aurvo.

Send Files to TV

Download on your phone, then send the file to the TV.

  1. Install Send Files to TV on both your phone and your TV.
  2. Tap Download on this page to save the APK to your phone.
  3. Open the app on both devices on the same Wi-Fi and send the file to the TV.
  4. Open the file on the TV, allow unknown apps if asked, and install.

Then sign in. Add your Xtream Codes login or M3U link from your provider, or scan the QR code to type it on your phone.
